# SmModule 后端文档索引

> 文档角色：`SmModules`、`SmModuleSql`、`SmModuleColumn` 动态页面元数据的渐进式披露入口  
> 适用范围：`eu.core/**` 中的模块维护、公共查询、缓存、导入导出及数据库配置  
> 最后核对：2026-08-07

## 使用方法

不要从头读取本目录全部内容。先按任务选择专题文档，再核对相邻源码、实体、数据库和测试：

| 任务 | 必读 | 继续核对 |
|---|---|---|
| 理解三表关系、页面组装和缓存 | [元数据模型与维护约束](元数据模型与维护约束.md) | `SmModulesServices`、`ModuleInfo`、`ModuleSql`、`ModuleSqlColumn` |
| 新增、修改、复制、删除或导入模块配置 | [元数据模型与维护约束](元数据模型与维护约束.md)、[配置脚本说明](配置脚本说明.md) | 三个实体、写入服务、事务、权限和缓存刷新 |
| 对照 SQL 示例或生成部署脚本 | [配置脚本说明](配置脚本说明.md)、[前端表单控件类型](../../frontend/SmModule/表单控件类型.md) | [`examples/`](examples)、目标环境映射和事务方案 |
| 判断现库结构或历史数据问题 | [数据库只读核对基线](数据库只读核对基线.md) | 重新执行经授权的只读核对；不得把历史快照当实时结果 |
| 修改返回前端的模块契约 | [元数据模型与维护约束](元数据模型与维护约束.md)、[前端 SmModule 索引](../../frontend/SmModule/README.md) | 后端 DTO/组装、前端类型、Redux 和通用组件 |

## 事实源优先级

1. 项目所有者在当前任务中的明确决定；
2. 根及后端 `AGENTS.md` 的强制约束；
3. 当前实体、服务、缓存实现、数据库结构和测试；
4. 本目录标记为当前约束或核对基线的文档；
5. SQL 示例、历史导出和设计说明。

SQL 示例是解释材料，不是现库事实源。文档与代码或数据库冲突时，先判断实现偏移还是文档过期，再同步更新对应文档和本索引。

- [`examples/供应商等级页面模块配置.sql`](examples/供应商等级页面模块配置.sql)：保留原始值序列的不可执行快照。
- [`examples/终端客户页面模块配置.sql`](examples/终端客户页面模块配置.sql)：结构完整但与现库不同的历史/迁移快照。
