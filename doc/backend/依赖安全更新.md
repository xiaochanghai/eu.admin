# 依赖安全更新（2026-11-21）

范围：BACKEND-PLATFORM、BACKEND-HOST（网关依赖）、DATABASE（数据库驱动依赖）。不改变表结构、连接配置或公开 API，不执行数据库迁移。

SignalR 1.2.14 本身仍引入 Http.Connections 1.2.13，故需显式覆盖。SqlSugar 引入 MySqlConnector、SQLite 和 Oracle 的加密依赖；文档处理依赖引入 Xml/Pkcs。保留现有上游版本及用户已有的升级，不进行无关主版本迁移。

MongoDB.Driver 升级到 3.14.1，使用上游配套的 SharpCompress 0.48.1 和 Snappier 1.3.1，不对旧驱动单独强制替换压缩 API。参见 [SharpCompress 公告](https://github.com/advisories/GHSA-6c8g-7p36-r338)、[Snappier 公告](https://github.com/advisories/GHSA-pggp-6c3x-2xmx)。驱动 3.14.1 加强了连接字符串脱敏、SASL PLAIN 的 NUL 校验和 SRV 主机名校验；仓库使用原始配置字符串创建 MongoClient，未发现将 MongoUrl/凭据的 ToString 结果重新当作连接字符串的调用。部署仍应验证 MongoDB 认证、压缩及读写；参考[驱动发布说明](https://github.com/mongodb/mongo-csharp-driver/releases/tag/v3.14.1)。

网关为 Swashbuckle 10.1.0 显式设置 Microsoft.OpenApi 2.7.5，保留 2.x API；不将使用旧版 OpenAPI 的其他宿主强制升级到新主版本。修复依据：[循环 schema 引用公告](https://github.com/advisories/GHSA-v5pm-xwqc-g5wc)。

SQLitePCLRaw 3.x 保留 bundle 入口，替换旧的原生库包；本次实际还原为 SQLite/3.53.4，依赖图不再含 SQLitePCLRaw.lib.e_sqlite3。参考[官方迁移说明](https://github.com/ericsink/SQLitePCL.raw/blob/main/v3.md)。原包漏洞见[SQLite 安全公告](https://github.com/advisories/GHSA-2m69-gcr7-jv3q)。其他修复依据：[Http.Connections](https://github.com/advisories/GHSA-67wp-ghc2-fw2g)、[WebUtilities](https://github.com/advisories/GHSA-6527-9fp8-r4x6)、[MySqlConnector](https://github.com/advisories/GHSA-473q-m89c-ghf8)、[Pkcs](https://github.com/advisories/GHSA-846f-f764-76mx)、[Xml](https://github.com/advisories/GHSA-r955-8q5j-3h83)。
