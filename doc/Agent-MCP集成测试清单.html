数据边界：使用隔离测试租户和账号，测试数据统一以 QA_AGENT_日期_ 开头。涉及创建、归档、取消、数据库重启的步骤不得在生产环境执行。服务令牌、签名密钥和连接串只通过安全环境变量提供，不记录在本清单。

执行顺序与准入条件

  1. 准备 SQL Server、Agent API、MCP API、React 管理端及隔离测试账号。
  2. 先执行 A 组冒烟测试；任一 P0 不通过，不进入业务回归。
  3. 依次执行 Unified Chat、后台任务、知识库、编排、MCP/BusinessQuery。
  4. 最后执行权限、异常恢复和发布门禁，记录 TraceId、RunId、TaskId 与截图。
  5. 发布标准：全部 P0/P1 通过；P2 失败必须有负责人、影响说明和修复计划。
