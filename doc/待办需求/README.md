# 待办需求索引

## 使用方式

1. 复制 [`TEMPLATE.md`](TEMPLATE.md) 创建独立需求文件。
2. 文件名使用 `REQ-YYYYMMDD-NNN-简短标题.md`，其中 `NNN` 为当天从 `001` 开始的序号。
3. 在下方索引登记需求，并同步维护状态、优先级和更新时间。
4. 需求完成或取消后保留文件和索引记录，不重复使用原编号。

## 状态说明

| 状态 | 含义 |
|---|---|
| 待分析 | 需求已登记，范围或方案尚未确认 |
| 待开发 | 范围和验收标准已明确，可以开始实现 |
| 待测试 | 开发已完成，等待测试 |
| 待验收 | 测试已通过，等待需求方验收 |
| 已完成 | 已验收并完成交付 |
| 已取消 | 明确不再处理，并在需求文件中记录原因 |
