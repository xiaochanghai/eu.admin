# 聊天页业务查询结果

`index.tsx` 中的 `BusinessQueryResultContent` 展示业务查询结果，兼容实时事件及历史消息的 presentation 数据。

- 有列定义时保留表头；结果行为空时，表格内跨列居中显示“暂无数据”。
- 有结果行时按原始展示值渲染，金额为零不视为空数据。
- 没有列定义时仍沿用文本回退展示，不把解析失败直接当成零行查询结果。
- 后端查询成功并校验后独立持久化消息和 `business-query-result` 事件，不依赖模型文本或运行成功终态。
  后续模型失败、超时或客户端取消不撤销已有查询结果；实时事件及历史恢复继续按 queryId 去重。
- 委派子 Agent 查询成功后会唤醒父入口立即保存并发送结果，不等待子流或子终态审计返回；事件结构和前端去重方式不变。

验证场景：空结果、有数据结果、零金额结果，以及历史空结果消息重新打开。
